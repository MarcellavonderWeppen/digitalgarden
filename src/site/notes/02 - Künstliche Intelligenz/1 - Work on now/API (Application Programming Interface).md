# API (Application Programming Interface)

👉 deutsch: **Programmierschnittstelle**

Eine Schnittstelle ist der Ort der Kommunikation.

Folglich ist eine Programmierschnittstelle der Ort, an dem sich zwei Computerprogramme begegnen und Daten austauschen können.

Der typische Fall: Eine App schickt über eine API eine Anfrage an einen Server. Der holt die gewünschten Daten aus seiner Datenbank und schickt sie zurück.
### Der Klassiker: die Wetter-App

Eine Wetter-App nutzt eine API, um Daten von einem Wetterdienst abzurufen. Die schöne Benutzeroberfläche zeigt die aktuelle Temperatur, aber im Hintergrund spricht die App über die API mit einem Server.
