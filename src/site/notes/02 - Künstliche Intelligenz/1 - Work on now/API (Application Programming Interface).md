# API (Application Programming Interface)

👉 deutsch: **Programmierschnittstelle**

Eine Schnittstelle ist der Ort der Kommunikation.

Folglich ist eine Programmierschnittstelle der Ort, an dem sich zwei Computerprogramme begegnen und Daten austauschen können.

Der Klassiker: wo Apps Daten von einem Server abrufen, der sie in einer Datenbank verwaltet.“
### Beispiel:

Eine Wetter-App nutzt eine API, um Daten von einem Wetterdienst abzurufen. Eine schöne Benutzeroberfläche zeigt die aktuelle Temperatur, aber im Hintergrund spricht die App über die API mit einem Server.
